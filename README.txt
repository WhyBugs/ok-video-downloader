ОК Видео 1.0 — Windows 10/11 (64 бита)

Установка: запустите OkVideo-Setup.exe и нажмите «Установить».
Права администратора не нужны. Ярлык появится в меню Пуск и, по выбору, на рабочем столе.
Для переносного запуска: dist\portable\OkVideo.exe (вместе с папкой tools).

1. Откройте видео в Одноклассниках или Яндекс Видео и скопируйте ссылку.
2. Вставьте ссылку в приложение, выберите папку и нажмите «Скачать MP4».
3. Дождитесь надписи «Готово». Кнопка «Открыть папку» покажет результат.

По умолчанию скачивается лучшее доступное качество. Можно выбрать предел 1080p, 720p или 480p.
Поддерживаются ok.ru/video/…, videoembed, мобильные ссылки m.ok.ru и odnoklassniki.ru.
Также поддерживаются yandex.ru/video/preview/… если исходный ролик размещён в Одноклассниках.
Если Яндекс запрашивает капчу, откройте исходный ролик на ok.ru и вставьте прямую ссылку.
Приложение скачивает один ролик, не плейлист. Трансляции не поддерживаются.
Закрытые, платные и удалённые видео могут быть недоступны; вход в аккаунт не реализован.
Отмена сохраняет частичную загрузку для продолжения при повторном скачивании в ту же папку.
Готовые файлы не перезаписываются. Если файл уже есть, приложение сообщит о нём как о готовом.
Скачивайте видео, которые вам разрешено сохранять.

Удаление: «Параметры Windows → Приложения → ОК Видео → Удалить».
Скачанные ролики и настройка выбранной папки остаются после удаления.
Установщик не имеет цифровой подписи издателя.

Сборка из исходников: powershell -ExecutionPolicy Bypass -File build.ps1
Необходим .NET Framework 4.5+ и инструменты в папке tools.
