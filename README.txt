DLP Видео 2.0 — Windows 10/11 x64

Запустите OkVideo-Setup.exe и нажмите «Установить». Права администратора не нужны.
Для обновления версии 1.0 сначала закройте приложение.
Переносная версия: вся папка portable, запуск OkVideo.exe.

Вставьте ссылки по одной на строку, выберите папку, формат и качество,
нажмите «Скачать / в очередь». «Узнать форматы» получает список потоков с сайта.
Двойной щелчок по готовой задаче показывает файл в Проводнике.

Видео MP4/MKV/исходный формат; аудио MP3/M4A/Opus/FLAC/WAV.
Плейлисты и диапазоны, очередь, отмена и повторный запуск.
Субтитры, обложки, метаданные, архив загрузок, шаблоны имён.
Cookies браузера/файла, прокси, скорость, параллельные фрагменты.
Дополнительные параметры и собственные команды настоящего yt-dlp.
Пример нарезки: --download-sections "*00:10-00:30" --force-keyframes-at-cuts

Поддерживаются сайты yt-dlp и ссылки Яндекс Видео на выбранный источник.
При капче Яндекс вставьте прямую ссылку источника. Доступность сайтов зависит
от сети и текущей поддержки yt-dlp; DRM не обходится. Cookies могут быть
недоступны из-за защиты браузера. Прокси применяется к yt-dlp;
страница Яндекс загружается через системное подключение.
MP4 сохраняет кодеки источника, без автоматического перекодирования в H.264.

Настройки и история: %LOCALAPPDATA%\OkVideo. Задачи сохраняют свои параметры.
История может содержать параметры доступа; храните её в своём профиле Windows.
После перезапуска нажмите продолжение очереди либо повторите прерванные задачи.
Удаление: Параметры Windows → Приложения → DLP Видео (yt-dlp).
Скачанные файлы сохраняются. Установщик не подписан издателем.

Исходники и полная инструкция: https://github.com/WhyBugs/ok-video-downloader
Компоненты включены: yt-dlp, FFmpeg, FFprobe, Deno; Python не нужен.
Сведения о лицензиях: THIRD-PARTY.txt и приложенные тексты лицензий.
