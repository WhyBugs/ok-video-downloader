# DLP Видео 2.0

Графическое приложение для Windows на базе настоящего [yt-dlp](https://github.com/yt-dlp/yt-dlp). Скачивает видео с Одноклассников, YouTube и других поддерживаемых yt-dlp сайтов. Принимает ссылки Яндекс Видео и извлекает ссылку выбранного источника.

## Установка

Скачайте **OkVideo-Setup.exe** из [последнего выпуска](https://github.com/WhyBugs/ok-video-downloader/releases/latest) и нажмите **Установить**. Windows 10/11 x64; права администратора, Python и отдельная установка инструментов не нужны. yt-dlp, FFmpeg, FFprobe и Deno включены. Установщик обновляет ОК Видео 1.0; перед обновлением закройте приложение.

## Использование

1. Вставьте одну ссылку или несколько, по одной на строку.
2. Выберите папку, формат и качество. Для точного выбора потоков нажмите **Узнать форматы**.
3. Нажмите **Скачать / в очередь**. Настройки сохраняются отдельно для каждой задачи.
4. Дождитесь завершения. Двойной щелчок по готовой задаче показывает файл в Проводнике.

- Видео: MP4, MKV или исходный формат; ограничение разрешения до 4K.
- Аудио: MP3, M4A, Opus, FLAC и WAV; качество и битрейт.
- Плейлисты, диапазон элементов, несколько ссылок, очередь, отмена и повторный запуск.
- Субтитры и автоматические субтитры, языки, встраивание; обложки, метаданные и JSON.
- Архив загрузок против повторного скачивания и шаблон имени файла.
- Cookies из браузера или файла, прокси, ограничение скорости и число параллельных фрагментов.
- Дополнительные параметры yt-dlp, предварительный просмотр команды, встроенная справка, список экстракторов и обновление yt-dlp.

Вкладка **Параметры yt-dlp** позволяет передать любые аргументы движку. Например, `--download-sections "*00:10-00:30" --force-keyframes-at-cuts` для фрагмента. Режим собственных параметров отключает автоматический выбор формата, качества, плейлиста и папки; эти параметры нужно указать самостоятельно. **Выполнить параметры** запускает самостоятельную команду yt-dlp, например `--help` или `--list-extractors`.

Выбранный MP4 сохраняет доступные кодеки видео; преобразование контейнера не означает перекодирование в H.264. Доступность сайта зависит от сети и текущей поддержки yt-dlp. DRM и доступ к удалённым роликам приложение не обходят. Cookies требуют доступного профиля браузера; извлечение может быть ограничено защитой браузера. Если Яндекс показывает капчу, вставьте прямую ссылку источника. Прокси применяется к yt-dlp; получение страницы Яндекс использует системное подключение.

История очереди и настройки хранятся в `%LOCALAPPDATA%\OkVideo`; после перезапуска ожидающие задачи запускаются кнопкой продолжения. Прерванные задачи можно повторить; частичные файлы используются для продолжения, когда это поддерживает источник. История содержит параметры доступа, поэтому используйте её на своём профиле Windows.

Удаление: **Параметры Windows → Приложения → DLP Видео (yt-dlp)**. Скачанные файлы сохраняются. Установщик не имеет цифровой подписи издателя.

## Проверки и сборка

Проверены настоящее скачивание MP4 из Одноклассников через предоставленную ссылку Яндекс, MP3 из Одноклассников и MP4 с YouTube. Локальные интеграционные проверки используют настоящее yt-dlp и FFmpeg: два элемента плейлиста, аудио, субтитры внутри MP4, обложка и метаданные, нарезка, архив повторов и отмена процесса. Проверены окно, список форматов и содержимое установщика. Проверка на одном компьютере и CI Windows; запуск другим человеком не требует файлов исходного проекта.

```powershell
powershell -ExecutionPolicy Bypass -File get-tools.ps1
powershell -ExecutionPolicy Bypass -File build.ps1
powershell -ExecutionPolicy Bypass -File tests/run-tests.ps1 -Integration
```

Результат: `dist/OkVideo-Setup.exe`. Переносная версия: вся папка `dist/portable`, запуск `OkVideo.exe`. Оболочка написана на C# / Windows Forms для .NET Framework. Точные версии и SHA-256 зависимостей закреплены в `tools.lock.json`. GitHub Actions собирает установщик и выполняет интеграционные проверки.
