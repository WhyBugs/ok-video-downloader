# ОК Видео

Приложение для Windows, которое скачивает видео из Одноклассников в MP4. Принимает также ссылки Яндекс Видео, если исходный ролик размещён в Одноклассниках.

## Скачать и установить

Откройте [последний выпуск](https://github.com/WhyBugs/ok-video-downloader/releases/latest), скачайте **OkVideo-Setup.exe**, запустите его и нажмите **Установить**.

Требования: **Windows 10/11, 64 бита**, доступ в интернет. Python и отдельная установка FFmpeg не нужны: все компоненты включены в установщик. Приложение устанавливается для текущего пользователя без прав администратора.

## Как пользоваться

1. Скопируйте ссылку на само видео из Одноклассников или Яндекс Видео.
2. Вставьте её в приложение.
3. Выберите папку и нажмите **Скачать MP4**.
4. Дождитесь сообщения **Готово**, затем нажмите **Открыть папку**.

По умолчанию приложение выбирает лучшее доступное качество. Можно ограничить качество до 1080p, 720p или 480p. В готовом MP4 сохраняются изображение и звук. Загрузку можно отменить и затем продолжить.

## Поддерживаемые ссылки

- `https://ok.ru/video/123456789`
- `https://ok.ru/videoembed/123456789`
- Мобильные ссылки `m.ok.ru` и ссылки `odnoklassniki.ru`.
- `https://yandex.ru/video/preview/123456789`, если источник — Одноклассники.

Закрытые, удалённые и платные видео могут быть недоступны. Вход в аккаунт и прямые трансляции не поддерживаются. Если Яндекс показывает капчу, откройте исходный ролик в Одноклассниках и вставьте его прямую ссылку. Скачивайте видео, которые вам разрешено сохранять.

Установщик не имеет цифровой подписи издателя. Удаление доступно в **Параметры Windows → Приложения → ОК Видео**. Скачанные видео после удаления сохраняются.

## Проверка

На Windows проверены окно приложения, обработка ссылок, отмена тестового процесса и содержимое установщика с сопоставлением SHA-256 всех файлов. По ссылке Яндекс Видео на ролик «МОЯ СТРАНА РОССИЯ КРАСОТА РОССИИ В HD» проверено настоящее скачивание: MP4 с H.264 и AAC, продолжительность около 180 секунд, включая выбор 480p.

Проверка выполнена на одном компьютере. Для запуска на другом компьютере не используются абсолютные пути исходного проекта или установленные инструменты разработчика.

## Сборка

Оболочка и установщик написаны на C# / Windows Forms и используют .NET Framework, входящий в Windows 10/11.

```powershell
powershell -ExecutionPolicy Bypass -File get-tools.ps1
powershell -ExecutionPolicy Bypass -File build.ps1
```

Результат: `dist/OkVideo-Setup.exe`. Для переносного запуска используйте `dist/portable/OkVideo.exe` вместе с папкой `tools`.

Проверки исходников:

```powershell
& "$env:WINDIR\Microsoft.NET\Framework64\v4.0.30319\csc.exe" /nologo /out:dist\portable\Checks.exe /reference:dist\portable\OkVideo.exe tests\Checks.cs
& .\dist\portable\Checks.exe
```

Зависимости: [yt-dlp](https://github.com/yt-dlp/yt-dlp) и [FFmpeg](https://github.com/yt-dlp/FFmpeg-Builds). Сведения о версиях и лицензиях — в [THIRD-PARTY.txt](THIRD-PARTY.txt). Исходники оболочки и установщика доступны по GPL v3 или новее.
